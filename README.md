# SolarOS

A production-oriented ERP dashboard for end-to-end solar EPC operations. The interface
covers business revenue, project activity, sales pipeline, inventory workflows,
customer management, quotations, service operations, and upcoming tasks.

## Run locally

Open `index.html` directly in a browser, or serve the directory with:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
